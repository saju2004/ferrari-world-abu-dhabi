# Ferrari World Abu Dhabi — Asset System Directory & Specification

This folder hosts all media assets for the Ferrari World Abu Dhabi web experience.
Any missing asset is automatically rendered by the web application using an editorial neutral-gray silhouette placeholder with technical labeling and dimensions.

To supply licensed press imagery, replace or drop the exact files into the respective directories listed below.

---

## 1. `/public/assets/logos/`
Official Ferrari World & Scuderia Ferrari marks.
- `ferrari-shield.png` [PRESENT] — Ferrari Prancing Horse shield emblem (512x640px, PNG with transparency or black background)
- `ferrari-world-badge.png` — Ferrari World Abu Dhabi logo mark (800x400px, transparent PNG or SVG)
- `scuderia-ferrari-wordmark.svg` — Official Scuderia Ferrari typographic logotype
- `heritage-1929.png` — Historical 1929 Scuderia shield
- `heritage-1947.png` — 1947 First Maranello Cavallino Rampante
- `heritage-1960.png` — 1960s Scuderia Formula 1 racing emblem
- `heritage-modern.png` — Modern unified Maranello emblem

*Notice: Per brand guidelines, all marks are displayed with the caption "Official marks – used with permission".*
